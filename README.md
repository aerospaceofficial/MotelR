# MotelR

MotelR is a SwiftUI front-desk app for independent motels. It grew out of a family motel's paper registration workflow. The app brings guest check-in, checkout, room assignments, signatures and PDF receipts into one iOS project.

## Run locally

Open MotelR.xcodeproj in Xcode 26 or later. Allow Xcode to resolve ZIPFoundation, select the MotelR scheme and an iPhone simulator, and press Run. For a physical device, configure your own signing team and bundle identifier in Signing & Capabilities. Use fictional guest information when trying out the app or reporting an issue.
